# WRA STEM Kits logo

The logo used on wrastem.com: a hexagonal plant cell with its nucleus and one organelle, beside the
name set in Bricolage Grotesque ExtraBold. The lettering in these files is outlined, so the files look
the same everywhere, with or without the font installed.

| File | Use it for |
|---|---|
| `wra-stem-kits-logo.svg` / `.png` | **Main logo.** Dark green-black on a transparent background, for white or light paper |
| `wra-stem-kits-logo-on-green.svg` / `.png` | Logo on the site's green, ready to drop into slides or documents |
| `wra-stem-kits-logo-white.svg` / `.png` | Light logo on a transparent background, for dark or photo backgrounds (looks empty in most image viewers; that's normal) |
| `wra-stem-kits-mark.svg` / `.png` | The cell symbol alone, dark |
| `wra-stem-kits-mark-white.svg` / `.png` | The cell symbol alone, light |
| `wra-stem-kits-icon.svg` / `.png` | Square app icon / profile picture (same as the site's favicon) |

PNG sizes: logos 2400 px wide, symbol and icon 1024 × 1024. Use the SVG files when you can; they stay
sharp at any size.

## Colours

| Name | Hex | Where |
|---|---|---|
| Leaf green | `#124A2B` | Main brand colour, backgrounds |
| Ink | `#13261C` | Logo and text on light backgrounds |
| Paper | `#F6F7F2` | Logo and text on green |
| Sunflower | `#F6C343` | Buttons and highlights (the nucleus in the icon) |

Leave clear space around the logo of at least the height of the letter "W", and don't stretch,
recolour or add effects to it.

Font: Bricolage Grotesque, SIL Open Font License 1.1 (see `../fonts/OFL-Bricolage.txt`).
